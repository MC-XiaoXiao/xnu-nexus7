# XNU for Nexus 7 (2012)

An experimental port of the XNU kernel to the Tegra 3-based Nexus 7 (2012, grouper/tilapia), with basic platform support for serial output, interrupts, and timers. Hardware bring-up is still in progress.

## Original project

Based on [HTC-Leo-Revival-Project/xnu](https://github.com/HTC-Leo-Revival-Project/xnu) at commit `d5c85d9b54bc27c338e69ff75dce2386dcfd723a`, with the existing HD2 modifications retained.
